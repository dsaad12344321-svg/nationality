# التقرير اليومي للجنسيات

تطبيق Next.js لتحويل ملفي `nat.xml` و`man.xml` إلى تقرير Excel عربي.

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000` وارفع الملفين من الواجهة.

## النشر على Vercel

1. افتح https://vercel.com/new وسجّل الدخول.
2. استورد المستودع `dsaad12344321-svg/nationality` من GitHub.
3. اترك Framework Preset على Next.js وأبقِ إعدادات البناء الافتراضية.
4. اضغط Deploy. لا يحتاج التطبيق إلى متغيرات بيئة.

## الخصوصية

يتم إرسال الملفين إلى مسار API أثناء إنشاء التقرير فقط، ولا يحتوي التطبيق على كود لتخزين الملفات بشكل دائم.

## ملاحظات

- الحد الأقصى لحجم كل ملف 20 ميجابايت.
- يعتمد التقرير على أسماء الحقول والتصنيفات الموجودة في ملفات XML، ويستخدم كتل `DAY` فقط لقيم `man.xml`.
